📚 Zotero (export automatique)

Sauvegardez les pages que vous lisez directement dans Zotero. Nécessite Zotero ouvert sur votre ordinateur (l'application desktop).

État inconnu
Cliquez sur "Tester" ci-dessous

Tags ajoutés à chaque item sauvé. Séparez par virgules.

Comment ça marche ?
  1. Ouvrez Zotero (application desktop)
  2. Clic droit sur une page → 📚 Sauver cette page dans Zotero
  3. Magic Pointer détecte automatiquement les articles scientifiques (DOI, journal, auteurs) via les meta tags standards (citation_*)
  4. L'item apparaît instantanément dans Zotero — collection sélectionnée

Pour articles scientifiques, Magic Pointer extrait automatiquement : titre, auteurs, journal, DOI, volume, pages, ISSN, date, résumé.
