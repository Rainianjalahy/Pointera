Magic Pointer

Configurez votre curseur intelligent. Pointez. Demandez. Agissez.

1. Choisir le moteur IA

Mistral est recommandé : modèle européen, données en Europe, gratuit jusqu'à un certain seuil.

2. Clé API Mistral

Obtenez votre clé sur console.mistral.ai/api-keys

2. Clé API Claude

Obtenez votre clé sur console.anthropic.com

3. Préférences

Comment utiliser

  1. Activez Magic Pointer avec Alt+M (ou clic-droit → « ✨ Magic Pointer »)
  2. Tapez votre commande dans la boîte qui apparaît (ou cliquez une suggestion)
  3. L'IA analyse le contexte visuel autour de votre curseur et répond en quelques secondes
  4. Utilisez le résultat : Copier, Insérer, ou relancer
